# 📝 Todo List

A modern and responsive **Todo List** web application built using **HTML, CSS, and JavaScript**. This project helps users create, organize, and manage their daily tasks through a clean and intuitive interface.

The application allows users to add new tasks, mark them as completed, edit existing tasks, and delete tasks whenever needed. To ensure that tasks are not lost after refreshing or closing the browser, the project uses **Local Storage**, providing a simple and persistent task management experience without requiring a backend or database.

## ✨ Features

* ➕ Add new tasks
* ✏️ Edit existing tasks
* ✅ Mark tasks as completed
* 🗑️ Delete individual tasks
* 💾 Automatic data saving using Local Storage
* 🔄 Tasks remain available after page refresh
* 📱 Responsive and user-friendly interface

## 🛠️ Built With

* HTML5
* CSS3
* JavaScript (ES6)
* Local Storage API

## 🎯 Purpose

This project was created to strengthen core front-end development skills by practicing **DOM manipulation**, **event handling**, **JavaScript logic**, and **browser Local Storage** while building a practical, real-world application.
